# Matrices
## Caracteristicas
- Las matrices son una especie de vectores anidados
- Pueden ser cuadradas. Quiere decir que sus dimensiones son iguales
- Sus elementos son numeros enteros

Un ejemplo en python seria este
```bash
import numpy as np
matriz = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print(matriz)
```
